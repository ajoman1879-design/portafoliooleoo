# Demos Web de Leo

Abrí `index.html` en esta carpeta para mostrar las cuatro demos desde una sola portada. No se necesita instalar nada: funciona al abrir el archivo y también está preparado para GitHub Pages.

| Demo | Nivel | Desde |
| --- | --- | --- |
| NEXUS — Ingeniería e infraestructura | Básico | ₲700.000 |
| VOLTA — Energía y proyectos | Profesional | ₲1.200.000 |
| ORBIT — Producto digital | Completo | ₲2.000.000 |
| ATELIER — Tienda de moda | E-commerce | ₲2.000.000 |

Cada demo es ficticia, responsiva y tiene la firma fija `Diseñado por Leo`. ATELIER incluye categorías de Mujer, Hombre y Niños; detalle de prendas, bolso persistente, eliminación de productos, cuenta opcional y checkout de demostración. Ninguna compra ni pago es real.

## Publicarlo gratis con GitHub Pages

1. Creá una cuenta en [GitHub](https://github.com) si todavía no tenés una.
2. Elegí **New repository**, poné un nombre (por ejemplo, `portfolio-leo`) y crealo como **Public**.
3. En tu computadora, abrí la carpeta `web_demos`. Seleccioná **todo lo que hay dentro** (incluyendo `index.html`, las carpetas `nexus`, `volta`, `orbit` y `atelier`) y subilo al repositorio con **Add file → Upload files**. No subas la carpeta `web_demos` como una carpeta adicional: `index.html` debe quedar en la raíz del repositorio.
4. Cuando termine la carga, hacé clic en **Commit changes**.
5. Abrí **Settings → Pages**. En **Build and deployment**, seleccioná **Deploy from a branch**. Elegí la rama `main`, carpeta `/(root)` y presioná **Save**.
6. Esperá uno o dos minutos. GitHub mostrará la dirección pública, normalmente `https://TU-USUARIO.github.io/portfolio-leo/`.
7. Abrí ese enlace y compartilo con tu cliente. Desde la portada podrá entrar a cualquiera de las cuatro demos con un clic.

Para actualizar el portafolio después, reemplazá o subí los archivos modificados al mismo repositorio; GitHub Pages publicará los cambios automáticamente en unos minutos.

Para un sitio real, reemplazá los textos, imágenes, correo, WhatsApp, redes y mapa por los datos del cliente. Las fotos de producto usadas en ATELIER provienen de VDR; confirmá siempre la licencia y el uso comercial adecuado antes de publicar un proyecto real.
